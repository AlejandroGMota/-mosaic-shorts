## 1. «Instalaste una librería de IA y te robó las llaves» — LiteLLM 1.107.0 comprometido (21 oct)

- **Hook (10 s):** "El martes, quien hizo `pip install litellm` durante una hora se llevó un regalo: un programa que se ejecuta cada vez que arranca Python y manda tus llaves de AWS, SSH y tus tokens de Claude y Cursor a un servidor ajeno."
- **Mecanismo a animar:** paquete → wheel con carpeta `cook/` que no existe en el código fuente → `cook.pth` en site-packages → *cada* arranque de Python ejecuta `import cook` → infostealer recorre carpetas (`~/.ssh`, `~/.aws`, `.env`, variables de entorno) → POST cifrado a un dominio falso parecido a `litellm.dev`; además un RAT que cada hora pide código nuevo y lo ejecuta. Ventana: pip 11:39–12:47 UTC; Docker hasta 14:20 UTC.
- **Qué cambia para quien hace software para clientes:** los gateways de LLM (LiteLLM y similares) viven en el mismo servidor que las llaves de API de *todos* tus clientes y del bot de WhatsApp. Fija versiones (lockfile con hashes), no uses la etiqueta `latest` en Docker, no actualices el mismo día que sale una versión, y separa credenciales por cliente para que un robo no se lleve todo. Si instalaste en esa ventana: rota todas las credenciales de esa máquina.
- **Formato:** noticia en 45 s + "qué cambia para mí".
- **Fuentes:**

  - LiteLLM — aviso de seguridad del 21 oct (enlazado por Aikido): https://docs.litellm.ai/blog/security-incident-oct-21-2026
  - Contexto, mismo patrón en npm (Shai-Hulud/ChainDrop, agosto): https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack

## 2. «Los agentes de código pasan las pruebas… pero 3 de cada 4 veces dejan el hueco» — benchmark LSCBench (14–16 oct)

- **Hook (10 s):** "Le pidieron a seis agentes de código que arreglaran 450 tareas reales. Pasaron hasta el 91% de las pruebas. Pero cuando les lanzaron el exploit original, el mejor solo aguantó una de cada cuatro."
- **Mecanismo a animar:** tarea (prompt solo funcional, nunca menciona seguridad) → agente genera código → doble compuerta: (1) tests funcionales → menta 73.6–91.3%; (2) se repite el exploit real (150 vulnerabilidades, 24 tipos CWE) → solo 16.4–25.1% sobrevive. Dos barras que se separan.
- **Qué cambia para quien hace software para clientes:** "pasa los tests" ya no basta como criterio de aceptación del código del agente. Pide la seguridad explícitamente en el prompt, agrega pruebas de abuso (inyección, permisos, entradas raras) y revisa a mano lo que toca auth, pagos y datos de clientes. Mito vs realidad: "si compila y pasa, está bien".
- **Formato:** mito vs realidad.
- **Fuentes:**
  - Tech Insider — AI Coding Agents: 91% Pass Tests, Only 25% Secure: https://tech-insider.org/ai-coding-agents-91-percent-tests-25-percent-secure-2026/
  - Paper LSCBench en arXiv (2610.14766): https://arxiv.org/abs/2610.14766 *(enlace citado por la nota; verificar antes de publicar)*

## 3. «Tu bot de WhatsApp ya cobra por responder» — nuevas tarifas de WhatsApp Business API (desde el 1 oct)

*No es de esta semana exacta (entró el 1 oct), pero es la primera quincena con facturas reales y pega directo a los bots de clientes.*

- **Hook (10 s):** "Hasta septiembre, contestarle a un cliente dentro de las 24 horas en WhatsApp era gratis. Desde octubre, después del mensaje mil del mes, cada respuesta se cobra."
- **Mecanismo a animar:** ventana de servicio de 24 h (reloj) → contador mensual por número: 1–1,000 gratis (menta) → desde el 1,001 cada mensaje se cobra a tarifa de utility del país (ámbar); las plantillas utility dentro de la ventana también pasan a cobrarse; marketing en México sube de $0.0305 a $0.0397 USD (+30%). Cálculo en pantalla: "si tu bot manda X mensajes al mes…".
- **Qué cambia para quien hace software para clientes:** hay que rediseñar bots: respuestas más completas en menos mensajes (no partir una respuesta en 4 burbujas), medir mensajes por número, avisar al cliente antes de su factura y recalcular el precio de mantenimiento. El costo por token de los agentes de Meta también existe. Formato "cuánto cuesta" con cuentas reales (pendiente: tarifa utility de México en la tabla oficial de Meta).
- **Formato:** cuánto cuesta.
